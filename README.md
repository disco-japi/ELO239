# Pasos para ejecutar

Copiar el repositorio en una carpeta local desde github. Posteriormente abrir QT creator, seleccionar abrir proyecto, buscar la carpeta Stage(numero) y seleccionar
el archivo CMakeLists.txt para abrir el proyecto, apretar la opcion "configure project" y finalmente hacer click en el boton de **play verde** en la parte inferior izquierda.
